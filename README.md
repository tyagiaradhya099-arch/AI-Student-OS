# AI Student OS

An AI-powered student productivity web application built with Flask.

## Features
- 📅 Calendar
- ✅ Task Manager
- 📝 Notes
- ⏱️ Pomodoro Timer
- 📊 Dashboard
- 🤖 AI Study Planner (Gemini API)

## Tech Stack
- Python
- Flask
- HTML
- CSS
- JavaScript
- SQLite
